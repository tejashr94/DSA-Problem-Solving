# Maximum Number of Non-Overlapping Palindromes

Given a string `s` and an integer `k`, find the maximum number of non-overlapping palindromic substrings whose length is at least `k`.

## Key Requirements
- Every selected substring must be a palindrome.
- Every selected palindrome must have length at least `k`.
- Selected substrings must not overlap.
- Maximize the number of selected palindromes.
